# E2E Runner Fixes and Verification

Date: 2026-10-02. Workspace changes based on `add48f0961ae90a860e8a01c96080fb48140f3d4`; no application, dependency, or lockfile changes.

## Changes

- Draft restoration tests locate the Drafts region, exact title text, and target href, without requiring the entire link's accessible name to exclude the date.
- Home routing verifies both personal `/home` and Team-enabled `/knowledge` (including navigation when sources/documents already exist), without requiring an empty workspace. Team-fixture routing cases are explicitly skipped in personal mode.
- The runner explicitly controls E2E Team mode through `KM_E2E_PERSONAL_ONLY`. It defaults to Team-enabled instead of inheriting product `.env` defaults injected by dotenv; discovery and execution use the same mode, and cleanup restores the original environment.
- Playwright `--list --reporter=json` determines the selected specs. The runner uses origin helpers referenced by each spec to decide whether teams-closed, SSO personas, or an unconfigured server is required; anonymous reading no longer depends on a second SSO app. The full suite retains all permission/identity servers.
- Timing covers discovery, DB initialization, fixtures, build, server readiness + browser tests, cleanup, and total; failures also print durations of completed stages. Child exit status, cleanup on cancellation, and parsing JSON only after captured stdout completes are preserved.

These were resolved intermediate failures and are not counted as final passes.
