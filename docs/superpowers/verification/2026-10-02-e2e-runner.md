# E2E runner 修正與驗證

日期：2026-10-02。基於 `add48f0961ae90a860e8a01c96080fb48140f3d4` 的工作區修改；沒有改 application、dependency 或 lockfile。

## 修改

- 草稿恢復測試以 Drafts region、精確標題文字及目標 href 定位，不要求整個 link 的 accessible name 排除日期。
- 首頁 routing 同時驗證 personal `/home` 和 Team-enabled `/knowledge`（包含已有 source/document 的導向），不要求工作區為空。Team fixture 路由案例在 personal 模式明確跳過。
- runner 以 `KM_E2E_PERSONAL_ONLY` 明確控制 E2E 的 Team 模式。預設 Team-enabled，不沿用 dotenv 注入的 product `.env` 預設；discovery 與執行使用同一模式，cleanup 還原原有環境。
- Playwright `--list --reporter=json` 決定所選 spec。runner 依 spec 引用的 origin helpers 決定是否需要 teams-closed、SSO personas 或 unconfigured server；匿名讀取不再依賴第二份 SSO app。Full suite 保留所有權限／身份伺服器。
- 計時涵蓋 discovery、DB 初始化、fixtures、build、server readiness＋browser tests、cleanup 和 total，失敗同樣輸出已執行階段耗時。保留 child exit status、取消時的清理，以及 captured stdout 完成後才解析 JSON。
