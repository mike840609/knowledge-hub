## Delivered

- My Space: scoped Search, My folders, Continue reading when available, Updates, existing Favorites when available, secondary drafts/notes/export. Compact existing PageHeader/list tokens retained.

- Archive safety: previous/incoming/matched/archive counts and percentage. Complete archive, empty incoming, mass archive, or low overlap requires source-name acknowledgment tied to exact plan hash, checked inside server Apply.
- Checking: Check for changes, cancellation, no-Apply scan failure copy, creator-private unexpired pending previews, distinct expiry/source-conflict guidance. Lost committed Apply responses recover the same run.

Active document/source filtering avoids archived broken links. Home3runs×5articles; full20runs×50articles, exact counts and paged history links for remaining details.
- Provenance and health: source/path on Home, Updates, search and reader Details, copy-path action. Existing indexed link resolver powers unresolved/ambiguous diagnostics and recorded import warnings. Stale workspace indexes explicitly mark checks incomplete. Images unchanged.

## Independent review and decisions

One fresh whole-branch review found no Critical and four Important issues. All four were fixed in one pass: archived article visibility, unbounded Updates, repeated complete Health edge scans, and old-only large diffs. The Minor high-risk E2E stopping before confirmation was also fixed. Its scenario now applies typed acknowledgment and verifies the archive result; another Apply deliberately loses a committed HTTP response and recovers. No review findings deferred.

Ruling: Worktree uses already-ignored .superpowers/worktrees and original checkout returns to main — existing feature branch preserved; no product scope change.
Ruling: Skill scripts are cloud resources without an executor path; generate equivalent briefs/ledger locally with the same per-task BASE/tests/commit record — bookkeeping only.
Task 2: Ruling: canonical state exposes optional revisionNo from its existing SQL join — avoids per-change revision lookups on 20,000-entry imports; legacy in-memory states use findById fallback. Cost if wrong: additional field compatibility, covered by reconciler tests.
Task 4: Ruling: added indexed source/path entry lookup instead of loading all canonical bodies for one diff — preserves lazy bounded reads; cost: one compatible port method.
Ruling: creator-private pending previews reuse indexed snapshot query; ambiguous Apply recovery first checks state then retries the same snapshot — idempotency preserves the run.
Ruling: Updates omits archived sources while history remains explicitly available with archived revision links — matches normal reader navigation; historic runs remain durable.
Ruling: provenance uses batched source-entry lookups; no new search filters or Markdown parsing — empty search pages avoid DB work.
Ruling: index completeness is conservative at workspace scope because existing index-state port is workspace-scoped — may show incomplete for another source; avoids false clean without new rebuild behavior.
Ruling: Full Updates caps each run at 50 article rows with exact added/updated counts and View all changes history link — keeps 20-run pages bounded while all details remain available in paged history.
Ruling: Health retains workspace-wide catalog for cross-source resolution but reads at most 1,001 source edges and 51 warning records per page — necessary catalog semantics, bounded detailed rows; pages with only valid links may offer Next issues without findings.
Ruling: Diff fallback reserves line/byte budget for both versions, including giant single-line changes — preserves readable incoming text while explicitly truncated.
Ruling: Formatting limited to newly added files and semantic repository changes; restored formatting-only rewrites of existing files — keep review scope focused.
Ruling: Preserve the feature branch/worktree after development and screenshots — the current request authorizes implementation and comparison; no new integration decision is needed to deliver them. Cost: branch remains available for a later PR.
Ruling: Add readable persisted result totals after visual inspection — required success summary was previously behind technical details; small UI-only correction with observed RED→GREEN and final browser smoke.

## Practical limits

Large diffs are intentionally truncated. Full Updates uses a per-run article limit with history links for remaining items. Health still needs the existing workspace catalog for cross-source name resolution; detailed edge/warning reads are bounded, and workspace-wide stale state is conservative. Historical details for pre-migration runs cannot be reconstructed reliably. Browser filesystem access remains a user-granted browser capability; background synchronization and image/attachment binaries are outside approved scope.
