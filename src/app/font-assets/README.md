# Inter

The Latin subset of Inter's normal variable font (weights 100–900) is vendored here so Next.js builds do not fetch Google Fonts. The font is served by the application through `next/font/local`.

Source: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2

License: SIL Open Font License 1.1; see `OFL.txt` (from https://github.com/google/fonts/tree/main/ofl/inter).

Keep the font and its license together when updating the asset. Other characters use the existing system font fallback.
