# Glossary

- **Source**: a folder of Markdown files imported into a workspace.
- **Preview**: the check that shows what an import would add, change or archive, with any warnings.
- **Apply**: the step that writes the previewed changes.
- **Archive**: the state of a document whose file was removed; it is kept, with its history, and out of the way.
- **Wikilink**: a link written between double square brackets; see [[concepts/links]].
