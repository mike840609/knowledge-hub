# Links

Notes can point at each other, and every link below really works.

- By title: [[Leave policy]] links to a note by its title.
- By file name: [[glossary]] needs only the name, without folders.
- With a folder: [[handbook/leave-policy]]. The folder part is optional; add it when two notes share a name. It can be a partial or a full path from the folder you import.
- A relative Markdown link: [onboarding](../handbook/onboarding.md).
- To a heading inside a note: [Approvals](../handbook/leave-policy.md#approvals).

Links resolve only inside one workspace, never across workspaces. To see what happens to links when files change, read [[Keeping in sync]].
