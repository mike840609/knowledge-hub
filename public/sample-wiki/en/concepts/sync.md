# Keeping in sync

Importing a folder is one-way. The local folder is authoritative: edit your files there, not in the Hub. Imported documents are read-only in the Hub.

When you change the folder, select it again, then use Preview and Apply. New files are added, changed files get a new revision, and files you removed become archived rather than deleted.
